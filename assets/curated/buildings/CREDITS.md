# Downtown architecture assets

Original generic 3D buildings by **Innerscene Corp**, released as **CC0 1.0 Universal**. The original GLB copyright fields include the same dedication. Neither model claims to represent a specific named building.

- [Twenty-storey glass office tower](https://www.innerscene.com/tools/library/3d-parts/twenty-storey-glass-office-tower-0f2e9425)
- [Mixed-use high-rise](https://www.innerscene.com/tools/library/3d-parts/mixed-use-high-rise-27a41221)
- [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)

Local derivatives combine the source geometry by material and resize embedded textures. They retain the original modeled sills, fins, balconies, podium, roof details, and furnishings without decimation. The office tower uses original night-lit glazing treatments for this city. Both files use standard binary glTF 2.0 in a gzip envelope for smaller downloads. `manifest.json` records original source hashes and direct download URLs.

The adjacent signature towers are original geometry created for this portfolio. Design references included the terracotta and setbacks of [111 West 57th Street](https://111w57.com/design/), the stepped and planted massing of [VIA 57 West](https://big.dk/projects/via-57-west-2350), and the composition of stone and glass on [35 Hudson Yards](https://www.som.com/projects/35-hudson-yards/). No reference imagery is shipped in the scene.
